## О демо

Интерактивный HTML-прототип компонента «ДОГОВОР» — мастера подключения договора эквайринга (открывается с главной страницы раздела «Эквайринг»). Описание главной страницы ниже — контекст.

- Статус макета: согласован и реализован.
- Состояния компонента (по Figma): первый вход, способы оплаты, эквайеры (варианты «Текущий» и «Иконки 24»), терминал, интернет, QR-код, кассовая ссылка, сохранение способов оплаты, партнеры, карточки договора (СБП, интернет, терминал: пустая → просмотр → редактирование кнопками ✓ / ✎), облачная касса, окно ЮKassa.
- Язык интерфейса: русский.
- Экран: 1024×768 (ноутбук), как в прототипе Figma.

### Что на странице (по БП)

Двухколоночный реестр с виджетами аналитики по онлайн-оплатам.

- **Слева** — сквозной мастер со списком договоров эквайринга: выручка и % комиссии по договору, разрезы по компаниям, эквайерам и типам оплат. Клик на узел фильтрует реестр, клик на «>>» открывает договор.
- **Справа** — вкладки:
  - **Оплаты** — счётчики (Ждём от банка, Комиссия, Возврат, Приход; показываются только при наличии данных), виджет «Динамика оплат» (сравнение с другим периодом), реестр документов оплаты.
  - **Поступления** — реестр банковских платежей по договорам эквайринга.
  - **Отчёты** — реестр загруженных отчётов эквайеров.
- **Кнопка основных действий** (на всех вкладках) — меню: создать документ оплаты, добавить договор эквайринга, загрузить отчёт.
- **Фильтры:** период — глобальный, по умолчанию текущий месяц, сбросить нельзя. На вкладках свои быстрые фильтры и поиск (на «Отчётах» поиска нет).
- **Состояния:** первый вход (нет договоров), один договор без движений, один договор, несколько договоров одного эквайера, много договоров по нескольким эквайерам, точкам продаж и компаниям.

## Структура проекта

- `index.html` — демо.
- `CLAUDE.md` — правила работы и команды.
- `PLAN.md` — план работ и статус.
- `variants.html` — статичные варианты верстки экрана «Эквайеры» для сравнения.
- `fonts/`, `img/` — шрифты и картинки.
- `_bp/` — материалы БП (только локально, в репозиторий не попадают).
