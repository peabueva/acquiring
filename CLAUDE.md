# Правила проекта

## Порядок работы

- Вопросы → план → один пункт → остановка: показать результат и перечислить допущения → ждать «ок» → следующий пункт.
- Задавать вопросы перед стартом и по ходу работы.
- Наращивать функциональность постепенно: сначала статичный каркас.
- Коммит и пуш — только по команде «закончила», не после каждой правки.
- Если записано «правило: …» или «запиши себе: …» — добавить в этот файл.

## Команды

- «начала» — забери все правки из репозитория, прочитай README и план, скажи, на каком пункте мы остановились;
- «статус» — что сделано, что в работе, что осталось, какие вопросы открыты;
- «закончила» — закоммить и запушь в main, обнови статус в плане, пришли ссылку на демо (проверь, что она открывается).

## Шаблон демо

- Шапка: название, версия, статус согласования.
- Экран 1024×768 (правило проекта: как в прототипе Figma; по умолчанию в шаблоне 1600×900).
- Вспомогательная панель справа: сценарии/состояния, ссылки.
- Автомасштаб: шапка, экран и панель масштабируются вместе под окно браузера с сохранением пропорций, без скролла.
- Окна и попапы — внутри экрана.

## Figma и компоненты

- Figma только читать, никогда не изменять.
- Демка повторяет макет как есть: варианты и состояния, которые есть в макете (в т.ч. «Вариант: Текущий/Новый» на его панели), переносим все, переключаемыми, а не выбираем один.
- Читать из Figma только узлы, нужные для текущего шага, а не весь файл.
- Правило: режим редактирования не выносить в отдельные сценарии панели — переключение только по кнопкам в интерфейсе (✓ / ✎).
- Компоненты и токены (цвета, отступы, тени) — из ui-kit: https://mariesmi.github.io/ui-kit/catalog/#all, только те, что используются в макете.
- ui-kit и чужие демки/репозитории — только читать и копировать нужное к себе в проект; никогда не коммитить, не пушить и не открывать PR в них.
- Шрифты: Inter и иконочный — лежат в проекте.

## Репозиторий

- README: первым блоком всегда ссылки (демо, макет, БП, согласование); новые ключевые ссылки добавлять туда же.
- Описание в README держать в соответствии с текущей версией демо.
- `_bp/` — внутренние материалы, в репозиторий не коммитить.
- Язык интерфейса — русский.
